# Precy Beauty Salon Appointment System

A web-based appointment scheduling and client management system designed to streamline bookings, service management, and customer scheduling for Precy Beauty Salon.

## 🚀 Key Features

* **Client Booking:** Easy online appointment scheduling for salon clients.
* **Service Management:** View and select from a detailed menu of salon services and pricing.
* **Schedule & Availability:** Real-time tracking of staff availability and open appointment slots.
* **Admin Dashboard:** Manage bookings, view appointment calendars, and handle customer records.

## 🛠️ Tech Stack

* **Frontend:** HTML, Tailwind CSS
* **Backend:** Laravel
* **Database:** MySQL
